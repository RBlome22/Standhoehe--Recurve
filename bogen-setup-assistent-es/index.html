Puesta a punto del arco paso a paso

Este tercer programa combina las dos aplicaciones existentes en un proceso guiado. Las aplicaciones individuales se mantienen por separado.

Orden recomendado:
1. Optimizar el fistmele y conseguir una agrupación reproducible.
2. Después ajustar el punto de enfleche y la rigidez dinámica con 3 flechas emplumadas + 3 flechas desnudas.
