# Standhöhe Recurve Optimierer – Netlify / GitHub Pages

Dieses Paket ist fertig vorbereitet, damit die App als kostenloser Web-Link per WhatsApp gestartet werden kann.

## Enthaltene Dateien

- `index.html` – die komplette App
- `manifest.webmanifest` – Web-App-/Home-Bildschirm-Informationen
- `icons/` – App-Symbole für iPad/iPhone
- `netlify.toml` – optionale Netlify-Einstellungen
- `.nojekyll` – GitHub-Pages-Kompatibilität
- `STARTANLEITUNG.txt` – kurze Anleitung

## Netlify

1. ZIP entpacken.
2. Auf `https://app.netlify.com/drop` gehen.
3. Den kompletten entpackten Ordner in das Netlify-Fenster ziehen.
4. Netlify erzeugt eine Webadresse.
5. Diese Webadresse per WhatsApp verschicken.

## GitHub Pages

1. Neues GitHub-Repository erstellen.
2. Alle Dateien aus dem entpackten Ordner hochladen.
3. In GitHub: Settings → Pages.
4. Source: `Deploy from a branch`.
5. Branch: `main`, Ordner: `/root`.
6. Speichern.
7. Den erzeugten Link per WhatsApp verschicken.

## Schüler-Anleitung

1. Link aus WhatsApp auf dem iPad/iPhone antippen.
2. Falls WhatsApp den Link intern öffnet: Teilen → In Safari öffnen.
3. Foto laden oder Kamera verwenden.
4. Zwei Kalibrierpunkte auf dem Scheibendurchmesser setzen.
5. Sechs Pfeile markieren.
6. Standhöhe eintragen und Serie speichern.
7. Nach den Serien optimale Standhöhe ablesen.

## Zum Home-Bildschirm hinzufügen

In Safari:
1. Teilen-Symbol antippen.
2. `Zum Home-Bildschirm`.
3. Name: `Standhöhe Recurve`.
4. Hinzufügen.
