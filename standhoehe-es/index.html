Inicio online mediante enlace de WhatsApp

Esta versión está preparada para Netlify o GitHub Pages. Después de publicarla, solo hay que enviar el enlace web por WhatsApp. Los alumnos abren el enlace en Safari; así la selección de fotos, el marcado y la evaluación funcionan de forma fiable como aplicación web.

Indicaciones para WhatsApp

Esta aplicación funciona como archivo HTML independiente. Para compartirla por WhatsApp, es preferible utilizar el enlace web y abrirlo en Safari en el iPad o iPhone.

La aplicación puede funcionar sin conexión. WhatsApp normalmente no ejecuta archivos HTML directamente; en ese caso hay que abrirlos desde la app Archivos.

Procedimiento de prueba

Para cada valor de fistmele se tiran 6 flechas. En cada tanda se descarta un impacto atípico. La aplicación calcula el área convexa de la agrupación restante en cm². El fistmele con el área más pequeña se marca como óptimo.
