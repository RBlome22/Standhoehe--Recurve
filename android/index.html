Installation

Falls der Knopf nicht aktiv wird:
In Chrome oben rechts auf ⋮ tippen und „App installieren“ oder „Zum Startbildschirm hinzufügen“ wählen.
  1. Diese Seite in Google Chrome öffnen.
  2. Warten, bis „✓ Offline-Daten gespeichert“ erscheint.
  3. „App installieren“ antippen oder das Chrome-Menü verwenden.
  4. Installation bestätigen.
  5. Danach Bogen Setup über das neue Symbol starten.
  6. Zum Testen Flugmodus einschalten und App erneut öffnen.
